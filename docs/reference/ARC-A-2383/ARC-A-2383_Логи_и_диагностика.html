Сформировать диагностический пакет

Расширенные технические проверки для анализа специалистами поддержки. Диагностический файл формируется локально и не отправляется автоматически.

ВМ для диагностического пакета

По умолчанию выбраны все связанные ВМ. При необходимости исключите отдельные узлы; исключение не изменяет область просмотра проверок.

Часть связанных ВМ исключена. Диагностический пакет может не содержать данных о причине неисправности.
Период выгрузки
Полная выгрузка может включать гигабайты данных. Для безопасности нужны лимиты размера, времени и свободного места; при их достижении пакет должен явно отмечать неполноту.
Планируемый итог — защищённый диагностический пакет для передачи в СТП. Клиент не видит внутренний HTML/Markdown-отчёт, который строится отдельной утилитой после расшифровки. Техническая интеграция пока не реализована.
Сертификаты не включены в диагностику — для них предусмотрен отдельный раздел. Без непрерывного сбора метрик пиковые CPU/RAM за прошлый период не отображаются.
