ВКС и медиа

Управление поддерживаемыми профилями качества видео и внешними IP-адресами WebRTC/Odin. Изменения могут потребовать перезапуска медиакомпонентов.

Встречи доступны
Прототип: изменения отображаются локально. Фактическое применение, доступные профили и правила работы с несколькими адресами требуют проверки командой.

Внешние IP WebRTC

Укажите адрес или два адреса, по которым один и тот же media-контур должен быть доступен клиентам.
Указывается только IP-адрес. Порт 1030 используется автоматически.
Добавить второй внешний IP
Используйте этот режим, если тот же WebRTC media-контур должен быть доступен через два внешних адреса.
При двух внешних IP система автоматически переводит сетевые точки прослушивания Odin на все интерфейсы. Администратору не требуется отдельно изменять внутренние адреса media-компонентов.
