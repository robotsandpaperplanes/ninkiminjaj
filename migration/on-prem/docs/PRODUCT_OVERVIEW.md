# Product overview

The On-Prem Administration Panel prototype gives an installation administrator a single conceptual flow for high-impact operations: inspect the current state, enter a change, check it, review impact, confirm, apply, and inspect the result. It covers TLS certificates, product licensing, and network addresses. Its interface text is Russian.

The intended audience is an administrator of a customer-managed MTS Link On-Prem installation, including installations with multiple products and VMs. The UX aims to show affected products, FQDNs, and nodes before applying a change, then report outcomes by product or node. Actual infrastructure discovery and application are outside the prototype.

The three exported screens are independent HTML/React prototypes. They illustrate a common administrative UI but are not yet a single routed application. A separate Cloud Administration Panel already exists in the receiving repository. The requested Cloud/On-Prem switch is an integration goal, not implemented in this export.
